# Listening Practice — Voyages 1

**来源**: TV5Monde Apprendre
**难度**: A1
**主题**: Deviner les destinations de vacances
**日期**: 2026-05-09

---

## 🎧 Avant l'écoute

**Objectif**: Comprendre un dialogue sur les voyages et les destinations

**Vocabulaire clé à préparer**:
- deviner, une destination, partir en vacances
- les continents: Europe, Afrique, Asie, Amérique, Australie
- les prépositions: en, à, au, aux

---

## 👂 Pendant l'écoute

**Points à écouter**:

1. **Les questions** — Repérer les structures interrogatives:
   - "Devinez où je pars…"
   - "Est-ce que c'est… ?"
   - Intonation montante pour les questions

2. **Les réponses géographiques** — Noter les prépositions utilisées:
   - "En Europe ?"
   - "Au Japon !"
   - "À la plage"

3. **Les expressions de réaction**:
   - "Ah ouais, cool"
   - "Oh, la chance !"
   - "Bon, allez…"

---

## ✏️ Après l'écoute

**Exercice**: Complétez avec les bonnes prépositions

```
1. Je vais _____ Mexique. (pays)
2. Elle part _____ Tokyo. (ville)
3. Ils voyagez _____ États-Unis. (pl.)
4. Tu restes _____ France. (f.)
5. Nous allons _____ sud. (direction)
```

---

## 🎯 Points de difficulté pour B2

| Aspect | Note |
|--------|------|
| 语速 | 快，适合练习快速反应 |
| 连读 | "aux États-Unis" 可能听不清 |
| 口语词 | "bah", "ouais" 需要适应 |
