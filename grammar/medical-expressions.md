# Grammaire — Expressions médicales et jugement

## 📌被动语态 (Passive Voice)

### 结构: être + 过去分词

```markdown
La vaccination est en baisse.
= 疫苗接种率正在下降

La rougeole a fait sa réapparition.
= 麻疹重新出现了
```

### 常见被动表达

| 主动句 | 被动句 |
|--------|--------|
| Les médecins soignent les patients. | Les patients sont soignés par les médecins. |
| Le vaccin protège. | On est protégé par le vaccin. |
| Les réseaux sociaux influencent les gens. | Les gens sont influencés par les réseaux sociaux. |

---

## 🔄 "être en + 名词" 表示状态

### 用法

```markdown
en baisse = 在下降
en hausse = 在上升
en danger = 处于危险中
en forme = 健康
```

### 例子

- La vaccination **est en baisse**. (疫苗接种率下降)
- Les prix **sont en hausse**. (价格上涨)
- La santé **est en danger**. (健康受到威胁)

---

## ⚠️ "sans" + 名词 vs "avec" + 名词

| 表达 | 含义 |
|------|------|
| sans complications | 没有并发症 |
| sans danger | 没有危险 |
| avec effets secondaires | 有副作用 |
| avec succès | 成功 |

## 💬 表达判断和建议

### 表示确信

| 表达 | 用法 |
|------|------|
| C'est vrai. | 这是真的 |
| Je suis sûr(e) que... | 我确信... |
| Il est certain que... | 肯定... |
| Effectivement | 确实 |

### 表示怀疑

| 表达 | 用法 |
|------|------|
| C'est faux. | 这是假的 |
| Ce n'est pas vrai. | 这不是真的 |
| Je doute que... | 我怀疑... |
| Ce n'est pas certain. | 不确定 |

## 🎯 练习题

### 1. 改成被动句

```
1. Les médecins soignent les malades. → _____ _____ _____ par les médecins.
2. Le vaccin protège les gens. → _____ _____ _____ par le vaccin.
3. Les réseaux sociaux influencent les patients. → _____ _____ _____ par les réseaux sociaux.
```

### 2. 填空

```
1. La vaccination est _____ baisse. (en下降)
2. La rougeole a fait sa _____ . (重新出现)
3. Cette information est _____ . (假的)
4. Le vaccin _____ les gens. (保护)
```

### 3. 判断真假

```
1. La rougeole est une maladie sans danger. → _____ (V/F)
2. Un malade peut contaminer beaucoup de personnes. → _____ (V/F)
3. Les réseaux sociaux jouent un rôle dans la confiance des patients. → _____ (V/F)
```
